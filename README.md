# Lost-and-Found-website

Campus Lost & Found is a simple and user-friendly web application designed to help students report and track lost or found items within a college or university campus.

The system allows users to submit details of lost or found belongings, including the item name, description, and location. All reported items are displayed in an organized list where users can easily browse entries, filter them by category (Lost or Found), and remove outdated records when necessary.

The application uses Local Storage to save data, ensuring that item records remain available even after refreshing the browser. Its responsive design provides a smooth experience across both desktop and mobile devices.

## Features

* Add lost or found item reports
* Store item details including name, description, and location
* Filter items by Lost, Found, or All categories
* Delete item records when no longer needed
* Persistent data storage using browser Local Storage
* Responsive and clean user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Browser Local Storage
